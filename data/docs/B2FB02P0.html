B2FB02P0Évolution des CITROËN AX GTI : Transmissions
Depuis MARS 1993, les véhicules CITROEN AX GTI sont modifiés comme suit.
1. Évolutions : Boîte de vitesses
1.1. Nouveau montage
Nouveau boîtier de différentiel à diamètre augmenté.
Diamètre (mm) = 77.
Repère médaille = 2CB92.
1.2. Ancien montage (rappel)
boîtier de différentiel : Diamètre (mm) = 69.
Repère médaille = 2CB79.
2. Évolutions : Transmissions
2.1. Nouveau montage
Figure : b2fp009c
Transmission nouvelle avec palier rapporté ( 1) ( côté droit).
Figure : b2fp00ac
Joints homocinétiques ( 2) : Diamètre (mm) = 86.
2.2. Ancien montage (rappel)
Joints homocinétiques ( 2) : Diamètre (mm) = 76.
3. Identification des pièces de rechange
Pièces de rechange nécessaires Numéro PR
Boîte de vitesses 22 00 QF
Transmission droite 96 170 670
Transmission gauche 96 170 671
Palier droit 96 171 582
4. Réparation
4.1. Boîte de vitesses
La nouvelle boîte de vitesses remplace l’ancienne.
4.2. Transmissions
Le montage d’une nouvelle transmission avec palier rapporté (côté droit) est possible sur tous les véhicules sortis antérieurement à la modification.
ATTENTION : Le panachage des anciennes et nouvelles transmissions est prohibé.
